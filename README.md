I have always been a creator. As a kid I built little castles for fire bugs and painted, first with crayons, then with acrylics. At 14 I started teaching myself web design and turned it into a side hustle. Code was first a means to an end for design, but once I started coding in undergrad I fell for how deterministic it is: how programs interact and the order they follow. AI has let me build more than ever over the past four years, so I follow my curiosity, find problems, and build solutions.
